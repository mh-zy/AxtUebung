# 主题配色文件格式（v1）

主题配色就是 **18 个十六进制颜色**；「主题预设」则是一整套 18 色的文本文件，在设置页里选中即刻生效。
格式沿用题库那套 INI 风格解析（`key = value`，`#` 或 `;` 开头是注释），纯文本、UTF-8、好手写也好 diff。

涉及三个地方：

| 位置 | 作用 |
| --- | --- |
| `<数据目录>/settings.txt` 的 `[ui]` 段 | 当前正在用的配色（17 行 `ui_color_*` + 一行 `ui_theme_name`） |
| `assets/presets/themes.txt` | 随程序打包的主题预设（现在有 11 套） |
| `<数据目录>/presets/themes.txt` | 你自己的预设：**存在就只用这一份**（整份替换，不是合并） |

数据目录：

* Windows：`AxtQuiz.exe` 同级的 `data/`
* Android：应用内部存储（`/data/user/0/com.axt.quiz/files`，可 `adb pull` 出来看）

---

## 一、18 个颜色项

键名与 `settings.txt` 里的完全一致；「分组」只是设置页上折叠用的四组（底色 / 文字 / 控件 / 状态）：

| # | 键名 | 界面上的名字 | 分组 | 默认值 |
| --- | --- | --- | --- | --- |
| 1 | `ui_color_bg` | 窗口底色 | 底色 | `D8DDE3` |
| 2 | `ui_color_panel` | 面板底色 | 底色 | `F0F2F5` |
| 3 | `ui_color_input` | 输入框底 | 底色 | `E2E6EA` |
| 4 | `ui_color_border` | 边框线 | 底色 | `B0B9C2` |
| 5 | `ui_color_text` | 文字 | 文字 | `1A1C1D` |
| 6 | `ui_color_text_muted` | 次要文字 | 文字 | `6A7278` |
| 7 | `ui_color_text_accent` | 强调文字 | 文字 | `8B0000` |
| 8 | `ui_color_button` | 按钮底 | 控件 | `C4CBD2` |
| 9 | `ui_color_button_text` | 主按钮文字 | 控件 | `1A1C1D` |
| 10 | `ui_color_button2` | 次按钮底 | 控件 | `D8DEE3` |
| 11 | `ui_color_icon` | 图标色 | 控件 | `3A434A` |
| 12 | `ui_color_scrollbar` | 滚动条 | 控件 | `8D969D` |
| 13 | `ui_color_accent` | 强调色 | 状态 | `B22222` |
| 14 | `ui_color_correct` | 答对 | 状态 | `5C1010` |
| 15 | `ui_color_wrong` | 答错 | 状态 | `D32F2F` |
| 16 | `ui_color_partial` | 部分分 | 状态 | `A93226` |
| 17 | `ui_color_draft` | 未提交（正在作答） | 状态 | `3F7FBF` |
| 18 | `ui_color_star` | 收藏星标 | 状态 | `D35400` |

颜色的写法：`RRGGBB`，**可以带一个 `#`**，大小写都认；必须正好 6 位十六进制。
写坏了只有那一项不生效（沿用原值），不会影响别的项。

## 二、当前配色：`settings.txt`

```text
[ui]
auto_next_on_correct = 0
ui_aspect = auto

ui_color_bg = 1E1E1E
ui_color_panel = 2D2D2D
ui_color_text = E0E0E0
...                      ← 17 行都要有；缺哪行就用代码里的默认值
ui_theme_name = 暗色护眼   ← 只是「上次选的是哪套预设」的记号，不影响颜色
```

* 在设置页里改颜色会**立刻**写回这个文件；手工改文件则要重启程序才生效
* 想回到出厂配色：设置 → 主题配色 → 展开「预设与应用」→「恢复默认配色」

## 三、主题预设：`themes.txt`

```text
# 注释行（# 或 ; 开头）
id = 1                     ← 遇到 id 就是新的一套（id 本身只用来分块，写什么都行）
name = 现代简约             ← 显示名：**没有 name 的块会被整块丢掉**
ui_color_bg = F4F5F7
ui_color_panel = FFFFFF
ui_color_input = E8EBF0
ui_color_border = D0D5DC
ui_color_text = 333333
ui_color_text_muted = 8C9AA6
ui_color_text_accent = 50E3C2
ui_color_button = A8C6E4
ui_color_button_text = 1A2530
ui_color_button2 = D6E4F0
ui_color_icon = 3A4A5A
ui_color_accent = 50E3C2
ui_color_correct = 52C41A
ui_color_wrong = F5222D
ui_color_partial = FFC107
ui_color_draft = 4A90D9
ui_color_star = FFB300

id = 2
name = 远山
...
```

规则：

* 一套预设从 `id`（或者第一个键值对）开始，到下一个 `id` 结束
* `name` 必填；颜色项可多可少 —— **没写的项保持当前值不动**（所以只改三五个颜色也行）
* 某一项颜色写坏 → 只跳过那一项；不认识的键名 → 直接忽略（不报错，也不会生效）
* `[themes]` 之类的段落标记会被忽略（写不写都行）
* 兼容早期版本的短键名：`bg` / `panel` / `text` / `button` / `accent` / `correct` / `wrong`，
  分别等于 `ui_color_bg` / `ui_color_panel` / `ui_color_text` / `ui_color_button` /
  `ui_color_accent` / `ui_color_correct` / `ui_color_wrong`

**在哪里看效果**：设置 → 主题配色 → 展开「预设与应用」→ 左上角下拉框里选一套。
提示条会说这次套用了几项，例如「已导入主题：现代简约（18 个颜色）」。

内置的 12 套（`assets/presets/themes.txt`）：现代简约 / 远山 / 青竹 / 醇厚琥珀 / 素笺 /
冷钢凝血 / 暗色护眼 / 玄墨 / 熔炉淬火 / 荒野锈迹 / 战损残阳 / 电子绿。

## 四、「复制主题文本 / 粘回来应用」

同一页上的这两个按钮用的就是上面的格式：

```text
ui_color_bg = F4F5F7
ui_color_panel = FFFFFF
ui_color_input = E8EBF0
...                       ← 复制出来是 17 行
```

* 「复制主题文本」把这 17 行放进剪贴板（Windows 端可用；Android 端剪贴板功能还没接）
* 「应用」把文本框里逐行的 `key = value` 套上去，认的键名完全一样

所以这份文本可以：

* 直接粘回另一台机器用（同一个 key 名，跨平台通用）
* 或者在开头加一行 `name = 我的配色`，整段存进 `themes.txt`，就变成一套预设

## 五、自己加一套预设

1. 在 `<数据目录>/presets/` 下建 `themes.txt`（Windows 就是 `AxtQuiz.exe` 旁的 `data\presets\themes.txt`）
2. 从 `assets/presets/themes.txt` 里拷一套出来，改 `name` 和颜色
3. 重启程序 → 设置 → 主题配色 → 预设与应用 → 下拉框里就有了

⚠ 数据目录里这份是**整份替换**打包那份，不是合并：`data/presets/themes.txt` 存在时，
`assets/presets/themes.txt` 就完全不读了 —— 想保留内置的 11 套，就得整份拷过去再改。

## 六、改代码时注意（加新颜色项）

颜色项由**两张表**描述，必须同时改：

| 表 | 位置 | 管什么 |
| --- | --- | --- |
| `kThemeColors` | `ui/src/SettingsScreen.cpp` | 界面：分组、显示名、默认值、设置字段 |
| `kFields` | `core/src/app/ThemePreset.cpp` | 预设文件：键名 → 设置字段 |

只改一边的后果：预设文件里写了这一项也不会生效（能解析出来，但套不上去）。
`tests/core_tests.cpp` 里的 `testThemePresetFile` 会直接读 `assets/presets/themes.txt` 校验
「每套都写全 18 项、每套都能套满」，就是防这种「文件改了、代码没跟上」的情况。

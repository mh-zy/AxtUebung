# 软件命名规范

最后更新：2026-10-20

| 场景 | 名称 |
| --- | --- |
| 简体中文界面 | 题斩 |
| English 界面 | AxeQuiz |
| 德语名称（预留） | AxtÜbung |
| 未知语言 / 无语言包兜底 | AxtUebung |

## 使用规则

* 界面上显示产品名时使用当前语言包里的 `ui.app_title`。
* Android 桌面名称按系统语言读取 `app_name`：中文“题斩”、英文“AxeQuiz”、德文“AxtÜbung”，其余语言兜底为“AxtUebung”。
* Windows 窗口标题跟随当前语言包中的 `ui.app_title`。
* 内部标识不随显示名变化：包名 `com.axt.quiz`、原生库 `axtquiz`、构建目标 `AxtQuiz` 和仓库路径继续保持原名，避免影响升级、数据目录与已有用户。

## 德语界面包

目前尚未内置完整的德语界面语言包，避免只翻译标题而形成中德混排。后续添加时使用：

```ini
[lang]
code = de
name = Deutsch

[text]
ui.app_title = AxtÜbung
```

完整德语包需要覆盖 `assets/lang/en.lang` 中的全部键，再放入 `assets/lang/de.lang`。

## 标题与桌面图标

* 首页标题使用 `assets/icons/axt-mark.svg` 加当前语言放大的 `ui.app_title` 文字。`CN_title.svg` 含 CSS 和 `<text>`，当前应用 SVG 解析器不支持直接把它当作单个图标纹理。
* Android 桌面图标以根目录 `axt-app-icon.png` 为母版，由 `tools/build-app-icons.ps1` 生成 mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi 五档方形和圆形 PNG。
* Windows 端不嵌入自定义 EXE 图标；当前只处理页内标题。
* 更换 Android 桌面图标后，测试设备可卸载重装以清除启动器旧图标缓存。

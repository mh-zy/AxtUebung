# 题库文件格式（固定格式 v1）

题库主体是**纯文本**，扩展名建议用 `.quiz`，文本编码必须为 **UTF-8**。
格式刻意做得像 INI：好手写、好 diff、出错能定位到行，而且不需要任何第三方库就能解析。

导入时还接受 `.txt`、`.text`，以及 Word 系列 `.doc`、`.docx`、`.docm`、
`.dot`、`.dotx`、`.dotm`。Open XML Word 文档会从 `word/document.xml`
提取正文；旧 `.doc` 只有在文件中的题库文本可恢复时才会导入。所有成功导入的
文件都会统一保存为 `.quiz` 纯文本。

程序会从两个位置找题库：

| 位置 | 说明 |
| --- | --- |
| `assets/banks/*.quiz` | 随程序打包（Windows 是 exe 旁的 `assets/`，Android 是 APK 里的 assets） |
| `<数据目录>/banks/*.quiz` | 用户自己的题库，**同名文件会覆盖**打包版 |

数据目录：

* Windows：`AxtQuiz.exe` 同级的 `data/`
* Android：应用内部存储（`/data/user/0/com.axt.quiz/files`，可 `adb pull` 出来看）

---

## 一、语法总则

```text
# 以 # 或 ; 开头的行是注释，整行忽略
[section]          ← 段落
key = value        ← 键值对（第一个 = 之后全部算 value）
```

* 值两端的空白会被去掉；
* 值里可以用转义：`\n` 换行、`\t` 制表符、`\\` 反斜杠；
* 出现的未知键会在界面里给出「题库提示」，不会导致解析失败（方便你发现打字错误）；
* 段落一共六种：`[meta]` 题库信息、`[q]` 一道题、`[material]` 一段材料、`[break]` 材料结束、`[exam]` 一套卷、`[draw]` 一条抽题规则（后两个是考试模式的**可选**段，见第七节）。

## 一之五、题型一览（支持情况）

### 已经支持

| `type` 写法 | 说明 | 答案怎么写 |
| --- | --- | --- |
| `single` / `单选` / `1` | 单选题（点一个选项） | 一个字母，如 `A`；也认 `1` |
| `multiple` / `多选` / `2` | 多选题（少选、多选都算错） | 逗号分隔，如 `A,C` |
| `judge` / `判断` / `3` | 判断题 | `T` / `F`（也认 对/错、正确/错误、是/否、1/2） |
| `fill` / `填空` / `blank` / `4` | 填空题（可以多个空，见下节） | 每个空的答案；空与空用 `;` 分隔，同一个空的多个可接受答案用竖线分隔，如 `H2O\|水 ; 100` |
| `indeterminate` / `不定项` / `partial` / `5` | 不定项选择题（少选给部分分） | 逗号分隔，如 `A,B` |
| `ordered` / `有序` / `排序` / `七选五` / `配对` / `6` | 多项有序选择题（七选五、段落大意配对、排序） | **按空的先后顺序写**，如 `B,D,A,C,F` |
| `material` / `材料题` | 「挂在某段材料下」的标记，**小题可以是任意题型** | 写 `material = <材料id>`；题型也能省略，由程序按数据判断 |

### 这几种题型怎么判分

| 题型 | 判分规则 |
| --- | --- |
| 填空 | 逐个空比对：忽略所有空白、忽略大小写（全角自动转半角）；全对算全对，只对一部分给部分分（对的空数 ÷ 总空数） |
| 不定项 | 选中的都在答案里 → 得分 = 选中数 ÷ 答案数；选到错的 → 0 分；全中 → 全对 |
| 多项有序 | 按空逐个比对，得分 = 对的空数 ÷ 总空数 |

部分分会写进进度文件（`score = 0.500`），界面上显示「部分正确，得分 50%」。
多选题（`multiple`）保持原样：少选、多选都算错，不给部分分。

### 填空题怎么写

**空号由你自己写在题干里**（程序不解析编号，只是按顺序在题干下面列出 1、2、3… 的输入框）：

```text
[q]
type = fill
stem = 水的化学式是【1】____，沸点是【2】____
blanks = 2                  # 空个数（可省；写了会跟答案个数核对一下）
answer = H2O|水 ; 100       # 每个空用 ; 分隔；同一个空的多个可接受答案用 | 分隔
analysis = 化学式 H2O，标准大气压下沸点 100℃。
```

- `blanks` 可以不写：空个数按答案里的 `;` 个数推断（只有一个答案就是单空，和老写法完全一样）。
- 判分：逐个空比对（忽略空白、忽略大小写、全角自动转半角）。全对算全对，只对一部分给部分分。
- 提交前要求**每个空都填上**（漏填的空按没答处理，交不了）。
- 作答内容（每个空填了什么）只在内存里，不写进度文件；进度文件只记对错与次数。
- 答案里不要出现 `|` 和 `;`：它们是分隔符。

### 材料题怎么写

材料放在 `[material]` 段里，**从 `[material]` 到 `[break]` 之间的小题都自动属于这段材料**；
**小题可以是任意题型**：单选、多选、判断、填空、不定项、多项有序都行，每道小题自己写自己的 `type`：

```text
[material]
id = m1
title = 短文：秋天的树
text = 第一行\n第二行

[q]
type = single
stem = 作者最喜欢哪个季节？
option = 春天
option = 秋天
answer = B

[q]
type = judge
stem = 短文里说这棵树冬天会开花。
answer = F

[q]
type = fill
stem = 短文写的是一棵____树。
answer = 槐树

[break]          # 材料到此结束，后面的题目不属于这段材料

[q]
type = single
stem = 下面这道题和上面那段材料无关
option = 甲
option = 乙
answer = A
```

不想用分组的话，也可以不写 `[break]`，改成在每道小题上写 `material = <材料id>` 显式挂上去，
两种写法等价、可以混用（自己写了 `material = <id>` 的以它为准）。

题型也可以省略：写 `type = 材料题`（或 `material`）时，程序按数据自己判断 ——

| 数据长什么样 | 判成什么题型 |
| --- | --- |
| 有 `blank` 行 | 多项有序 |
| 有 `option`，答案是 `A,B` 这种字母表 | 一个 → 单选；多个 → 多选 |
| 没有 `option`，答案是 `T` / `F` / 对 / 错 这类 | 判断 |
| 其余文字答案 | 填空 |

想写得明确一点，直接在小题上写 `type = single` / `multiple` / `judge` / `fill` /
`indeterminate` / `ordered` 就行（推荐这样写，尤其是「只有一个空的有序题」这种看不出来的情况）。

- 界面把一段材料画成**一页卷面**：材料正文在上面，下面依次是这段材料的所有小题，整页可以上下滚动；
  这一页处理完用底部的「下一段材料」翻到下一组。
- 卷面怎么交在「设置 → 答题 → 材料题卷面提交方式」里选：**逐题提交**（默认，每题下面有自己的提交按钮）
  或**整页提交**（卷面上不出现每题按钮，页面底部一个「提交本页」把已填的一起判掉）。
- 同一页里各题的答题方式按自己的题型走：选项按钮、填空输入框、「空 + 字母」可以混排在一页里。
- `text` 可以写多行，会自动拼成一段（换行也可以写成 `\n`）。
- `[material]` 段本身不是一道题，不占题目编号。
- 写了 `material = xxx` 却找不到对应 `[material]` 段时，导入会提示「题目引用了不存在的材料」。

### 现在还没有的

- 填空题的空号要自己写在题干里（程序只按顺序列出输入框，不去解析编号）。
- 填空题的答案里不要出现 `|` 和 `;`（它们是分隔符）。
- 卷面里的小题不参与「答对自动跳下一题」（一页里都看得见，跳反而碍事）。
- 整页提交只是「一起判分」；**整卷计时、及格线、按规则抽题组卷属于考试模式**，见第七节（题库里写了 `[exam]` 才能用）。

## 二、题库信息 `[meta]`

```ini
[meta]
id = demo-basic          # 必填，题库唯一标识（进度文件按它命名，改了就相当于换了一个题库）
title = 基础示例题库      # 显示名称
lang = zh-CN             # 题库内容语言
version = 1              # 题库格式版本
desc = 演示用的示例题库    # 说明（可选）
```

`id` 缺省时会用文件名代替。

## 三、一道题 `[q]`

每道题以一个 `[q]` 开始（写成 `[question]` 也可以）。

### 3.1 通用键

| 键 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 否 | 题目编号，缺省自动生成 `q1`、`q2`… |
| `type` | 否 | 题型：`single` 单选（默认）/ `multiple` 多选 / `judge` 判断 |
| `stem` | **是** | 题干 |
| `option` | 选择题必填 | 选项，可以写多行；至少 2 个 |
| `answer` | **是** | 正确答案，写法见下节 |
| `analysis` | 否 | 解析 |
| `tags` | 否 | 标签，用逗号分隔，例如 `tags = 数学,入门` |
| `difficulty` | 否 | 难度 1~5 |
| `score` | 否 | 分值（默认 1）；考试模式按它算分，`[draw]` 里的 `score` 会覆盖它 |
| `source` | 否 | 出处 |

### 3.2 答案怎么写

| 题型 | 写法 | 例子 |
| --- | --- | --- |
| 单选 | 一个字母或数字 | `answer = A` / `answer = 1` |
| 多选 | 多个用逗号分隔 | `answer = A,C` / `answer = 1,3` |
| 判断 | `T`/`F`，也接受中文 | `answer = T` / `answer = 对` / `answer = 错误` |

判断题的选项不用写，界面上固定显示「正确 / 错误」两个大按钮。

### 3.3 多语言（预留接口）

题干和解析可以给其他语言各写一行，键名是 `字段.语言代码`：

```ini
[q]
stem = 一个字节等于多少位？
stem.en = How many bits are there in one byte?
analysis = 1 Byte = 8 bit
analysis.en = 1 byte equals 8 bits.
```

界面语言为 `en` 时会优先显示 `stem.en`，没有对应翻译就回退到 `stem`。
（界面文案的语言包是另一套机制，见 `assets/lang/*.lang`。）

## 四、完整示例

```ini
# 我的第一份题库
[meta]
id = my-first-bank
title = 我的题库
lang = zh-CN

[q]
id = q1
type = single
stem = 中国的首都是？
option = 上海
option = 北京
option = 广州
answer = B
analysis = 北京是中国的首都。
tags = 常识
difficulty = 1

[q]
type = multiple
stem = 下面哪些是操作系统？（多选）
option = Windows
option = Linux
option = Word
answer = A,B

[q]
type = judge
stem = 水在标准大气压下的沸点是 100℃。
answer = 对
```

## 五、导出规则

界面里的「导出题库 / 导出错题本 / 导出收藏题」会写到一个新文件：

```
<数据目录>/export/<题库id>[-wrong|-marked]-<年月日-时分秒>.quiz
```

导出的文件**也是同一种格式**，可以直接再导入（放回 `banks/` 目录即可），
所以「导出 → 改 → 再导入」是一条闭环。导出的错题本会同时复制一份到 `<数据目录>/banks/`，
下次启动就能直接选用。

## 六、出错怎么办

1. 界面首页选中题库后，如果有 ⚠ 提示，点「题库提示」看具体第几行、什么问题；
2. 命令行也能校验：

   ```powershell
   build\win\bin\AxtQuiz.exe --validate D:\题库\我的题库.quiz
   ```

   输出示例：

   ```text
   题库：我的题库（3 题）
     第 12 行：answer 指向了不存在的选项：D
     第 18 行：未知的题目键：analysls
   ```

常见错误：忘了写 `answer`、选项少于 2 个、判断题答案写成了别的字、单选却给了多个答案。

## 七、考试模式：卷声明 `[exam]` / `[draw]`

考试模式**不是**每份题库都有的：题库里写了卷声明（`[exam]`）才能在首页点「考试」，
没写就点不动（灰着）。卷声明写在题库文件里，所以一份题库可以自带好几套卷，分享一个文件就够。

### 7.1 一套卷 `[exam]`

| 键 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 否 | 卷名（选卷框里显示的那一行；不写就用 `id`） |
| `id` | 否 | 卷标识，缺省自动生成 `exam1`、`exam2`… |
| `minutes` | 否 | 限时（分钟）；不写 = 不限时 |
| `pass` | 否 | 及格线（百分比 0~100）；不写 = 不判及格 |
| `seed` | 否 | 抽题种子：写了就每次抽到同一套题（模拟卷要能复现）；不写 = 每次重抽 |
| `shuffle` | 否 | `1` = 卷内题序打乱；默认**按题目难度由易到难**排 |
| `desc` | 否 | 说明（可选） |

```ini
[exam]
id = mock-a
title = 期中模拟卷 A
minutes = 60
pass = 60
seed = 2026
desc = 覆盖第一章到第三章
```

### 7.2 抽题规则 `[draw]`

写在它那套 `[exam]` 后面，几条规则按顺序拼成一张卷：

| 键 | 说明 |
| --- | --- |
| `count` | 抽几道题；`type = material` 时表示**几段材料**（跟材料里有多少小题无关）。不写 = 能抽多少抽多少 |
| `type` | 题型白名单，逗号分隔可多选（`single,multiple`）；写 `material` = 只抽材料题 |
| `difficulty` | 难度区间，写成 `2-5`（写单个数表示正好这个难度）；**没写难度的题不收** |
| `tags` | 标签，命中**任意一个**即可；不写 = 不限 |
| `exclude_tags` | 命中就排除（例如 `exclude_tags = 送分题`） |
| `material` | 只抽材料题：`any` = 随便哪段，也可以写某段材料的 `id` |
| `id` | 点名抽（写题目的 `id`，逗号分隔）；写了就不随机 |
| `score` | 这条规则抽到的每题分值；不写就用题目自带的 `score`（默认 1 分）。**材料段**：写了它，整段材料的总分必须正好等于它（对不上不进候选） |

```ini
[draw]
count = 6
type = single,multiple
difficulty = 2-4
tags = 第一章,第二章
exclude_tags = 送分题
score = 2

[draw]
count = 1
type = material        # 一段材料：它的小题整段一起进卷
score = 3
```

几条要点：

* **跨规则不重复**：一道题进了卷，后面的规则不会再抽到它；
* **普通规则只抽独立题**：材料段里的小题不会被 `type = single` 这类普通规则抽走；
  要抽材料请用 `type = material` 或 `material = <材料id>`，整段一起进卷；
* **材料题整段进卷**：抽中材料里的一道小题，会把整段材料的小题按顺序一起带进来
  （材料题要一页作答，拆开没意义）；`type = material` 时 `count` 数的是**几段材料**；
* **材料题的 `count` 数「段」，与小题数无关**：`count = 2` 就是两段材料，一段里塞了几道小题不影响数数。
  作为补偿，规则里**写了 `score` 就要求整段材料的总分（各小题分值之和）正好等于它** ——
  这样「一段材料 = `score` 分」是定的，卷面总分不会被材料里的小题数带偏。对不上的段不进候选，
  并会给一条能照着改的提示（`有 2 段材料的总分对不上，没进候选（现有材料段总分：2、4）`）；
* **抽不满不算错误**：能抽多少抽多少，同时给一条提示（`第 2 条抽题规则只抽到 3/6`），
  首页的「题库提示」和选卷框里都能看到；
* 卷面顺序默认**按难度由易到难**（同难度保持抽题顺序）；`shuffle = 1` 时按种子打乱
  （打乱以「一段材料」为单位，不会把材料拆散）。

### 7.3 分值

* 题目可以自带分值：`[q]` 里写 `score = 3`（默认 1 分）；
* `[draw]` 里的 `score` 覆盖题目自带的分值（**材料段例外**：它是「整段总分 = score」的筛选条件，各小题仍用自己写的分值，见下条）；
* **卷面满分** = 卷内各题分值之和；**得分** = 每题分值 × 该题 0~1 的得分（部分分按比例给分）；
* 及格线是百分比：`pass = 60` 表示「得分 ≥ 满分的 60%」。
* 材料段整段进卷时，各小题用**自己**的 `score`（跟不写 `[draw] score` 时一样）；写了 `[draw] score` 会先按
  「整段总分 = score」筛候选，所以一段材料贡献的分数就是那个 `score`。

### 7.4 考试时会发生什么

* 进考试后**不逐题判分**：可以随时改答案，界面只显示「已作答 / 未作答」（题目总览也只有灰 / 蓝两色）；
* 底部只有**交卷**（会先问一句「还有 x 题没作答」）；限时卷到点自动交卷；
* **交卷那一刻**才统一判分：答对 / 答错各记一次（错题照旧进错题本、累计统计照旧 +1）；
  **空着的题不写进度**（没答的题不该被记成错题），只在成绩里按 0 分算；
* 交卷后是**成绩页**：得分 / 满分、正确率、用时、及格与否、逐题得分与对错；
  点某一题可以回看判定与解析（这时才显示对错），底部「成绩单」按钮能再回到成绩页。

命令行也能校验抽题结果（不用开界面）：

```powershell
build\win\bin\AxtQuiz.exe --paper any --bank 4      # 卷 id 写 any = 该题库第一套卷
```

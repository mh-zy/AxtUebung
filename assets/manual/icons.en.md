# Icon guide

Icon colors follow the current theme's Icon color.

## Brand and Home

- @icon:axt-mark.svg Brand mark on the Home title.
- @icon:home.svg Return Home.
- @icon:upload.svg Import banks.
- @icon:stats.svg Open statistics.
- @icon:settings.svg Open Config.

## Practice modes

- @icon:layout-arrow-right.svg Linear practice.
- @icon:arrows-shuffle.svg Shuffle practice.
- @icon:current-location.svg Smart practice.
- @icon:view.svg Recite mode; answers are shown directly.
- @icon:scroll-text.svg Exam mode.

## Question actions

- @icon:star.svg Bookmark the current question.
- @icon:star-filled.svg Bookmarked; select again to remove.
- @icon:export-tags.svg View or add tags.
- @icon:grid.svg Open the question overview.
- @icon:file-x.svg Open the current bank's missed-question list.
- @icon:m-file-x.svg After entering from the missed list and answering correctly, remove the current question from it.

## Bank card

- @icon:file-x.svg Practice only missed questions from this bank.
- @icon:eraser.svg Clear this bank's answer data.
- @icon:trash-x.svg Delete a user-imported bank file.

## Export

- @icon:download.svg Export the whole bank.
- @icon:export-wrong.svg Export missed questions.
- @icon:export-marked.svg Export bookmarked questions.
- @icon:export-tags.svg Export questions by tag.

题斩（AxeQuiz）用户手册
版本：0.3.1-alpha
更新日期：2026-10-20

============================================================
一、软件简介
============================================================

题斩是一款本地优先的离线刷题应用，支持 Windows 和 Android。

主要功能包括：

- 导入自定义题库；
- 顺序、乱序、权重、背题和考试模式；
- 单选、多选、判断、填空、不定项、多项有序和材料题；
- 错题本、收藏、标签和答题统计；
- 主题配色、首页背景、界面比例、语言和提示词；
- 题库、错题、收藏题和标签题导出。

软件本身不联网，没有账号、广告、云同步或统计上报。

注意：当前为内测版本，不能保证程序一定稳定。重要题库和答题进度请定期导出备份。


============================================================
二、安装与启动
============================================================

【Android】

1. 获取题斩（AxeQuiz）的 APK 文件。
2. 在手机文件管理器中点击 APK。
3. 如果系统提示禁止安装未知来源应用，请按系统提示临时允许当前文件管理器安装应用。
4. 完成安装后，在桌面或应用列表中找到“题斩”。
5. 首次启动即可使用，不需要注册或登录。

Android 返回手势每次只返回一级页面；在首页连续返回两次才退出。

【Windows】

1. 解压完整的 Windows 版本压缩包。
2. 双击 AxtQuiz.exe。
3. 请勿只复制 exe 文件，旁边的 assets 和 data 目录也需要保留。

公开发布版本不附带内置题库。首次打开时题库列表可能为空，需要先导入自己的题库。


============================================================
三、导入题库
============================================================

1. 在首页点击右上角的导入图标。
2. 在系统文件选择器中选择题库文件。
3. 支持 .quiz、.txt 和 .text 文件。
4. 导入成功后，题库会出现在首页列表中。

题库文件要求：

- 使用 UTF-8 编码；
- 每份题库应包含唯一的题库 id；
- 如果导入时提示格式错误，请先检查题库是否缺少题干、答案或选项；
- 来源不明的题库可能包含错误答案，请自行确认内容。

Android 使用系统文档选择器，不要求广泛存储权限。应用只会读取你主动选择的文件。


============================================================
四、首页与刷题模式
============================================================

首页显示已导入的题库。点击题库卡片可以选中它。

底部“刷题模式”包括：

1. 顺序
   按题库顺序练习，优先出现未做或做错的题。

2. 乱序
   按随机顺序练习整个题库，已答对的题也可能作为复习出现。

3. 权重
   根据掌握程度、难度和标签选择更需要的题目。
   开轮后仍会在答题过程中继续补充后续题目。

4. 背题
   按题库顺序显示整个题库，直接展示标准答案。
   不受“每轮题数”限制。

5. 考试
   只有题库包含考试卷声明时才能使用。
   进入后会按试卷规则抽题并计时。

“每轮题数”可以限制顺序、乱序和权重模式的本轮题目数量。
背题和考试模式不受该数量限制。

选择模式和题数后，点击页面中的“开始练习”按钮进入答题。


============================================================
五、答题操作
============================================================

【单选题】

点击一个选项，然后点击“提交答案”。
如果在设置中开启“单选题点击选项即提交”，点击选项后会立即判分。

【多选题】

可以点选多个选项，全部选好后提交。
少选或多选都会判错。

【判断题】

选择“正确”或“错误”后提交。

【填空题】

在输入框中填写答案。多个空需要全部填写后才能提交。
输入内容会实时更新，不要求按回车。

【不定项题】

可以只选一部分。选中的选项都正确时按比例获得部分分；
选中错误选项则本题得 0 分。

【多项有序题】

按照题目要求的顺序，为每个空选择对应选项。

提交后会显示：

- 正确或错误；
- 得分；
- 标准答案；
- 解析，如果有。

答错或只拿到部分分的题会进入错题本。


============================================================
六、材料题
============================================================

材料题会把一段材料和它下面的若干小题放在同一页。

1. 材料正文显示在页面上方；
2. 小题按顺序排列；
3. 页面可以上下拖动；
4. 底部的“下一段材料”用于进入下一组材料。

材料题可以混合单选、多选、判断、填空等不同小题。

如果设置中选择“逐题提交”，每题下面会有自己的提交按钮。
如果选择“整页提交”，页面底部会出现统一的“提交本页”按钮。


============================================================
七、考试模式
============================================================

考试模式需要题库内包含试卷声明。没有试卷声明的题库不能开始考试。

基本流程：

1. 在首页选择“考试”；
2. 点击开始考试；
3. 选择一套试卷；
4. 查看试卷名称、时间、题量和及格线；
5. 点击“开始答题”；
6. 在考试过程中修改答案；
7. 点击“交卷”；
8. 查看成绩、正确率、用时和逐题结果。

考试过程中：

- 不会立即显示答案对错；
- 可以随时修改答案；
- 倒计时结束会自动交卷；
- 未作答的题按 0 分计算，但不会因为空题而被记为答错；
- 交卷后可以点题目回看答案和解析。


============================================================
八、错题本、收藏和标签
============================================================

【错题本】

答错或只拿到部分分的题会进入错题本。

连续答对达到一定比例后，题目会自动移出错题本。
该比例可在“设置 > 答题 > 错题移出比例”中调整。

从错题本进入答题并答对后，可以手动将该题移出错题本。

【收藏】

点击星标按钮可以收藏或取消收藏题目。
首页的导出功能可以单独导出收藏题。

【标签】

题目可以显示题库自带标签，也可以自己添加标签。
标签可用于按标签导出题库。


============================================================
九、结果与统计
============================================================

本轮结束后会显示：

- 本轮题数；
- 答对数量；
- 答错与部分分数量；
- 本次用时；
- 错题列表。

“数据统计”页面会累计显示：

- 累计答题；
- 正确数量；
- 正确率；
- 刷题总时长；
- 连续刷题天数；
- 各题库完成情况。

统计可以清零。清零前会要求再次确认。


============================================================
十、导出与备份
============================================================

导出类型包括：

- 导出整个题库；
- 导出错题；
- 导出收藏题；
- 导出指定标签的题目。

导出时可以选择保存位置。
导出的文件仍然是标准 .quiz 题库，可以再次导入。

建议定期导出：

- 重要的原始题库；
- 需要保留的错题；
- 自己整理过的标签题。

Android 系统备份已关闭。卸载应用或清除应用数据后，本地题库和进度不会由系统自动恢复。


============================================================
十一、设置
============================================================

【答题】

- 答对后自动跳下一题；
- 答对后停留时间；
- 单选题点击选项即提交；
- 材料题逐题提交或整页提交；
- 错题移出比例；
- 权重补题间隔；
- 统计页进入题库时使用的顺序。

【界面】

- 界面比例；
- 语言；
- 字体设置；
- 主题配色。

【主题配色】

- 可以展开或收起各个配色分组；
- 点击色块选择颜色；
- 也可以输入 RRGGBB 十六进制颜色；
- 支持主题预设、复制和应用主题文本。

【提示词】

提供中文和英文的题库格式修正提示词，可复制到支持长文本的 AI 工具中使用。

============================================================
十二、滚动手势
============================================================

长列表和长页面可以在内容区域直接上下拖动。

- 从空白处拖动可以滚动；
- 从按钮或输入框上纵向拖动也可以滚动；
- 点击和拖动之间有距离判断，轻微移动不会误触；
- 松手后会根据速度继续滑动一段距离；
- 按在右侧原生滚动条上时，由滚动条控制。


============================================================
十三、Android 返回手势
============================================================

Android 的返回手势按页面层级逐步返回：

- 设置子页返回设置根页；
- 设置根页返回首页；
- 从统计页进入刷题，返回统计页；
- 结果页返回进入前的页面；
- 考试成绩页回看的题目，返回成绩页；
- 首页连续返回两次才退出应用；
- 考试进行中返回会先询问是否放弃本场考试。

打开弹窗时，返回手势只关闭最上层弹窗，不会直接退出应用。


============================================================
十四、隐私与本地数据
============================================================

- 应用本身不连接互联网；
- 不收集账号、设备标识或广告信息；
- 不接入统计、崩溃上报或推送 SDK；
- 题库、进度、设置、主题和提示词保存在本机；
- 导入导出只访问用户主动选择的文件；
- Android 系统备份已关闭。

卸载或清除数据前，请先导出重要题库和进度。


============================================================
十五、常见问题
============================================================

1. 首次打开没有题库怎么办？

   公开发布版不自带题库。请点击导入按钮，选择自己的 .quiz 文件。

2. 导入失败怎么办？

   检查文件是否为 UTF-8 编码，题干、答案和选择题选项是否完整。

3. 题库里的中文显示异常怎么办？

   确认题库使用 UTF-8 编码，不要使用 ANSI、GBK 等编码保存。

4. 考试按钮不能点击怎么办？

   该题库没有试卷声明，不能使用考试模式。请使用包含考试规则的题库。

5. 为什么每轮题数和填写的数字不一样？

   背题和考试模式不受每轮题数限制。题库题目少于设定数量时，也只能抽取实际存在的题。

6. 为什么不显示答案？

   普通练习模式需要先提交答案。背题模式会直接显示答案。

7. 输入框无法输入怎么办？

   先点击输入区域，再使用系统键盘输入。若键盘未弹出，可退出输入框后重新点击。

8. 清除数据后还能恢复吗？

   不会自动恢复。只能从之前导出的题库备份重新导入。

9. 应用卡住或出现错误怎么办？

   请记录应用版本、手机型号、Android 版本和复现步骤，并发送到反馈邮箱。
